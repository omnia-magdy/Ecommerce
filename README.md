# 🛒 eCommerce Platform

A responsive and dynamic eCommerce website build using fundamental front-end web technologies.

##  Features
* **Dynamic Product Display:** Products loaded dynamically using JavaScript.
* **Data Management:** Products data structured in `items.json`.
* **Interactive UI:** Smooth transitions, cart capabilities, and user-friendly experience.

##  Tech Stack
* **HTML5:** Structure of the web platform.
* **CSS3:** Custom styling and responsive design.
* **JavaScript (ES6):** Dynamic components and logical interactions.
* **JSON:** Local data structure for items.
